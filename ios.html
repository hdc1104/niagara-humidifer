iPhone에서 Niagara 연결

iPhone에서 직접 BLE로 연결하려면 Web Bluetooth를 지원하는 브라우저가 필요합니다. 기본 Safari와 일반 iPhone Chrome만으로는 이 연결을 제공하지 못합니다.

  1. App Store에서 Bluefy – Web BLE Browser를 설치합니다.
  2. Bluefy가 요청하는 Bluetooth 접근을 허용합니다.
  3. Bluefy 주소창에 이 Niagara 웹앱의 HTTPS 주소를 입력합니다.
  4. 가습기를 iPhone 가까이 두고 다른 휴대폰·Mac 앱에서 연결을 해제합니다.
  5. 웹앱의 가습기 연결을 누르고 Niagara를 선택합니다.

사이트를 GitHub Pages에서 열면 Pages의 HTTPS 인증서를 사용합니다. 웹 파일만 GitHub에서 내려받고, BLE 연결은 iPhone과 가습기 사이에서 처리됩니다.

로컬 Mac 주소로 접속할 경우

192.168.x.x 로컬 HTTPS 서버는 직접 만든 CA 인증서를 사용합니다. iPhone에 인증서를 설치한 뒤 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 해당 CA의 SSL 신뢰를 별도로 허용해야 합니다. 설치만으로 자동 신뢰되지 않습니다. 인증서 오류를 무시해서 진행하지 마세요.

이 과정이 번거로우면 GitHub Pages에 게시된 HTTPS 주소를 사용하세요. 브라우저나 서버가 iPhone의 신뢰 설정을 자동으로 바꾸지 않습니다.

Apple 인증서 신뢰 안내

확인 범위

iPhone 안내와 BLE 브라우저 API 호환 처리를 준비했습니다. 실제 iPhone/Bluefy의 Niagara 연결은 아직 확인하지 않았습니다. 홈페이지를 홈 화면에 추가하는 것만으로 Safari에 Bluetooth 기능이 생기지는 않습니다.
