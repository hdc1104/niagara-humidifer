접속 및 연결 안내
가습기는 웹페이지를 연 휴대폰 가까이에 두세요. Mac 앱이나 다른 휴대폰이 연결되어 있다면 먼저 연결을 해제하세요.
HTTPS로 열었는데 연결 기능이 보이지 않으면 최신 삼성 인터넷 또는 Android Chrome에서 열어 주세요. 삼성 인터넷과 Chrome의 사이트 기기 권한은 별도로 허용해야 합니다. 일반 HTTP LAN 주소는 보안 환경이 아니어서 Web Bluetooth가 동작하지 않습니다.
이 Mac은 웹 파일만 제공합니다. BLE 데이터와 제어는 이 브라우저와 가습기 사이에서 처리됩니다.
